## 📝 Descrição

## Este projeto é uma interface web de um player de música, inspirada em plataformas de streaming, chamada Music Legends. O Código HTML define toda a estrutura visual de aplicação, enquanto o comportamento dinâmico (trocar músicas, tocar/pausar, menu responsivo) é controlado por JavaScript externo.
## O projeto se adapta perfeitamente a **computadores, notebooks, tablets e celulares**, apresentando uma **estrutura limpa e organizada**, com **imagens ilustrativas**, **cabeçalho com links**, **textos descritivos** e **botões de ação**.

---

## 🧩 Tecnologias Utilizadas

- 🌐 **HTML5** → Estrutura da página.
- 🎨 **CSS3** → Estilo, layout responsivo (Media Queries) e design visual.
- ⚙️ JavaScript — Implementação da lógica da aplicação, interatividade e manipulação do DOM.
